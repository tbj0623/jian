# 笺

一张纸、一枚印、一句话——帮你决定「这件衣服要不要买」「这桌人吃什么」「这句话什么时候提醒我」。
纯静态 H5（双击就能开），套一个 Capacitor 8 的安卓壳；判定默认走本地规则引擎，数据默认只落在这台设备。主动配置网关后，相关文字和照片会发往指定地址。

**不联网也能用。** 网关是可选的：填了它，多「认照片」和「抄截图」两条路；不填，三张笺照常出结论。

**开源：** 自有源码按 [MIT License](LICENSE) 发布；贡献说明见 [CONTRIBUTING.md](CONTRIBUTING.md)，安全报告见 [SECURITY.md](SECURITY.md)。模型密钥、Android 签名文件、真实用户备份及第三方网页抓取材料不属于公开源码。仓库不提供第三方模型额度或托管网关。

- 版本 **0.6.1** / `versionCode 29` / `minSdk 24` / `targetSdk 36`
- `index.html` 553 行：**24 个 `<script>`**、**7 个样式表**（另有 manifest + 2 个图标，共 10 个 `<link>`）、
  **17 屏**；**8 个 Capacitor 插件**
- 菜库 **63 道**、成就 **30 枚**、桌面快捷方式 **5 枚**、长图 **6 种**（全部 1080×1920）

## 三种跑法

### 一、双击 `index.html`（最快，什么都不用装）

不需要 Node、不需要构建、不联网。数据存在本机 localStorage。

窄到 360 宽、宽到桌面都能用：≥900px 时中间那一栏立成桌上的一张纸，底栏跟着收进列宽。
用 `http(s)` 打开时才会注册 `sw.js`（预缓存整份白名单，缓存名跟着版本号走），
断网或者装到主屏之后还能打开上次的界面；`file://` 下不注册，双击那条路保持原样。

### 二、出安卓包

```bash
npm install
npm run android    # debug APK（装了就能用，不需要签名配置）
npm run release    # 正式签名 APK + AAB
```

两条都会先跑 `build-www`（把 H5 按白名单拷进 `www/`）再 `cap sync android`，**不要在
`android/` 里直接敲 `gradlew`**——那样不会 sync，打出来的包跑的是上一版前端。

产物：

```
android/app/build/outputs/apk/debug/app-debug.apk
android/app/build/outputs/apk/release/app-release.apk
android/app/build/outputs/bundle/release/app-release.aab
```

签名细节（keystore 在仓库外、密码在 `~/.gradle/gradle.properties`）、iOS（只能在 macOS 上构建）、
PWABuilder 云打包这条备选路，都写在 [`docs/双端打包指南.md`](docs/双端打包指南.md)。

### 三、装现成的 APK

如果这个仓库是从别人那儿接过来的，`android/app/build/outputs/` 下可能已经有一个出好的包：

```powershell
adb install -r android\app\build\outputs\apk\release\app-release.apk
# 签名换了会 INSTALL_FAILED_UPDATE_INCOMPATIBLE：先 adb uninstall com.jian.app
```

出包机器上要在设备里验一遍的，看 [`docs/安卓自验指南.md`](docs/安卓自验指南.md)
（起模拟器、装包、走 CDP 验业务、点原生弹窗、逐条量）。

> **不要**在聊天沙箱或后台常驻挂服务器。

## 能做什么

### 今日 · 每天打开先看这一屏

- **每日三件事**，永远只有三件（多一件就变仪表盘）。三件分别从衣 / 味 / 言里挑，
  挑定之后**当天不再变**（存在本机 `jian.today`），白天再打开还是同三件；
  「再抽一笺」是用户主动要换，那才换
- 每一件都能**当场做完**：记一笔穿着、勾掉一条言笺、记「今天做了这道」。
  做完那行变成「✓ 今天做过了」但不消失——成果要看得见
- **往年今日**：去年（或更早）的今天你在这儿做过什么，按「月.日」跨年匹配
- **连续天数**：断了一天补得回来（补记昨天，一天只给一次）

### 衣笺 · 买之前先问柜子

四个页签：**过笺 / 柜子 / 搭配 / 愿望**。切页签不换屏，所以返回键不会在页签之间乱跳。

**过笺**

- 首屏那张大纸就是输入槽：没选图时是一枚没蘸墨的印加一句「点这张纸，放照片」
- 判定依据是**主色提取**（跳过白底黑底，不把条纹算成灰色）+ CIE Lab 感知色差；
  优先在同品类里找最像的那件——买第二件白衬衫才算重复，买一条配色不同的裤子不算
- 结论三枚章：宜入 / 再想想 / 先别。**柜里那件几乎一样却半年没穿**时，金句直接说破
- 也说能配什么（不同品类里挑颜色协调的，最多 3 件）
- **柜子太薄会自己说**：不到 5 件时附注、长图、复制出去的那份都写着「这个判定还薄」——
  薄柜子里「没有这个色」几乎不会错，但也几乎没用，不拿它冒充结论

**柜子**

- **记一次穿着，顺手算出这件每穿一次几块钱**：点开柜里那件 → 「今天穿了」，
  档案页那一行从「还没记价格。记了才看得到『这件每穿一次值几块钱』」变成
  「¥799 ÷ 23 次 = 每次 ¥34.7」，下面紧跟一句判词「一次 ¥34.7，还没穿回本。多穿它，或者下一件别这么买」
- 每件记着穿过几次、上次什么时候穿；**超过 90 天没动的次数角标标红**，可按「常穿 / 久未穿」排
- **穿着日历**：这个月哪几天穿了它，一格一天（有记录的那天是实底印章红）
- 按季节筛（全部 / 夏 / 春秋 / 冬）；季节按名字里的线索推断，也能在单品里手改，
  手改过的不会被品类改动冲掉
- 搜名字、品类、标签；标签最多 12 个
- 照片放不下时被清成色块，点那件用「相册补图」或「现拍一张」补回来——**只换照片**，
  名字、品类、季节、主色、穿过几次全不动
- 柜子那一页底部接**衣柜统计**：在穿率、单次成本均值、最久没穿的三件、忍住的金额

**搭配**

- 从柜里挑几件拼成一套，存进搭配册（最多 30 套），写一句场合与备忘
- 「今天穿这套」：整组一起记一笔穿着，每件的次数 +1，同时进行为流水（热力图 / 成就都读它）
- 搭配也能存成长图（1080×1920）

**愿望 · 冷静期**

- **想买的先放进愿望单，默认冷静 3 天**（「放三天，回来还想要再说」）。
  到期那一刻两处会叫你：衣笺那一屏的**「愿望」页签上亮一个小红点**、
  愿望页顶上那句从「冷静期到了会在这儿和页签上叫你回来看一眼」变成
  「其中 3 件冷静期到了，往下看看还想不想买」
- 每一项自己那一行写着还有几天：「还要冷静 2 天（第 1 / 3 天）」；
  到期那一行变成「冷静了 3 天，够久了。还想买吗？」，卡片左边多一道印章红竖线
- 点「不买了」当场 toast「不买了，省下 ¥799」，并给出**一次撤销**；
  之后愿望页顶上多一句「已经有 3 件决定不买，省下 ¥1,204」
- 这笔钱累在一处：**衣柜统计那一块的「忍住的」**——「在愿望单里决定不买的有 3 件，一共省下 ¥1,204」。
  没记价格的愿望不进这个数（说不清数额的钱算进去就是编数字，见 `wardrobe.js:738`）
- 「从上一张笺来」：刚过完的那件直接进愿望单（带品类、颜色、价格）

### 味笺 · 这桌人能点什么

四个页签：**排桌 / 做菜 / 买菜 / 这周**。

**排桌**

- 四气质（朋友 / 情侣 / 回家 / 同事）、11 种忌口、加人；忌口不摊开，每人只挂已选的那几枚
- 给出荤 / 素 / 汤 / 主食的现有结构、还差几道、**上菜顺序**（先上 → 清口 → 主菜 → 硬菜 → 汤 → 主食）
- **缺什么就推荐具体菜**，点一下直接进菜单
- **成分不只从菜名猜**：菜库自己记着每道菜会让哪些忌口的人吃不了——
  「小笼包（猪肉）」「干煸四季豆（辣 / 猪肉）」名字里没写原料也会亮起来
- **贴一整段话也行**：它先把「菜」和「关于这桌人的话」分开，
  但句子里写着的忌口真的算进雷区，并说清是从哪句话看出来的
- 「不吃香菜但爱吃辣」这种转折句分开判——忌的是香菜，不是辣
- 结果分三层：雷区（有人不能吃）/ 谨慎（含敏感成分但没人忌口）/ 全员安全
- **常一起吃饭的人存成组**（最多 12 组），下次一键拉回来；存的是快照不是引用
- 排过的桌留最近 4 桌，点一下把那一桌的菜单拿回来

**做菜**

- **63 道菜按荤 / 素 / 汤 / 主食分组的卡片网格**，组可折叠，一屏扫得到六到九道
- **菜谱详情**：这道菜会让谁吃不了、合不合季、做过几次
- **今晚吃什么转盘**：从当天这桌人能吃的里转，转完可以直接记「今天做了这道」
- 自己写菜谱（食材、步骤、用时，最多 40 张）——**正文只允许用户自己写**：
  从网上抓既有版权问题，也和「不联网也能用」直接冲突。所以一道菜可能「有卡」也可能
  「只有名字」，界面上必须区分得开，没有卡的菜不许假装能展开步骤

**买菜**

- 清单是菜谱的**派生物**：从菜谱详情点「去记要买」、从这周点「变成清单」，都会走到同一处
- **同名同单位要合并**（鸡蛋 2 个 + 3 个 = 5 个）；单位不同就并排摆着，不硬凑成一行
- **按货架分区**：蔬菜 / 肉蛋 / 水产 / 主食 / 调料 / 水果 / 其他——这是人在超市里走的顺序；
  也可以换成按加入时间排
- 勾掉就是一笔记录（成就「买到二十样」只有这一处在记）

**这周**

- 7 列网格，点格填菜；存过的周最多 14 张
- 一整周直接变成买菜清单

### 言笺 · 说过的话落成一张笺

- **捞成笺**：贴文字，捞成 待办 / 要买 / 已定 / 还没说清 四类。
  自动抽时间点（明天、这周五、下周三、9月28日、月底…）和人名；
  「周五把合同寄出」这种「有日期又是把 X 做掉」的句式也算待办
- **说话人徽章**：「小红：明天开会」标出小红，正文只留「开会」；
  「小王让我周四前把报价发过去」这种没冒号的写法一样认
- **分批贴不冲突**：第二贴按「类别 + 原话」去重合并，已经勾掉的那条不会被冲成新的
- **日历视图**：有时间的条目落在月历上，点一天看那天的事；卡片分白天 / 夜里两档，
  同一句话不会在凌晨三点找上门
- **归档**：办完满七天的自己收进归档，收的时候说一声、给一次反悔
- **摘录本**：一天最多一句，自己挑出来的那句话（和「笺册」不是一回事）
- **屏内快速添加**：定日子、挑重复（一次 / 每天 / 每周 / 每月）——不用 `prompt()`
- **提醒**：到点弹系统通知，走原生 `jian-remind` 渠道。
  文案永远写「大约这个点」，不写「准时」——没有精确闹钟权限，Doze 下本来就会晚几分钟
- 两条看法（按类型 / 按时间）、能搜（最多 200 条）、能勾、能挪类、能改时间、能复制整张笺

### 笺谱 · 用过的日子

从「今日」那一屏进，不占底栏（一周看一次就够）。

- **热力图**三档跨度（近 6 周 / 近半年 / 近一年），行 = 星期、列 = 周、五档深浅 + 今天带边框；
  打开就滚到今天；每一格点开是那一天的流水；方向键能走
- **四块统计**：衣 / 味 / 言 / 时。每一个数字都能反推成分子和分母
  （「在穿率 68%」下面必须有「37 件里 25 件穿过」），数据少就说薄，**0 不是结论**
- **30 枚成就章**，四组（衣 9 / 味 7 / 言 6 / 时 8）。每一枚都对应一件真的发生过的事；
  每一枚都算得出「还差几次」，进度一律现算、不落盘（删掉一条记录，那句话当天就得变）
- **年度总结**：月曲线、四格数字、两条最、一句从账本里挑出来的真话，
  可存成 1080×1920 长图

### 册 · 我的

- **个人主页卡**：用了多少天、攒了什么
- **三个入口**：设置 / 找东西 / 章
- **钱包与订阅**（演示版不接支付）
- **数据体检**：本机占用、各集合条数、上限还剩多少
- **数据与备份**：导出 / 导入 JSON、隐私政策入口、清空本地数据
- **算力网关地址**（可选）
- **笺册**：一屏里 24 张存档，点一下再复制当时那张笺、能看全文、能单删、能按衣 / 味 / 言只看那一笺

**导入是可逆的那一种**：备份里写着它是什么时候导的，导入完开机就报
「已导入：柜里 N 件 · 言笺 M 条 · 笺册 K 张（这份是 X 导出的）」，旁边一枚撤销换回导入前那一整份。

### 设置（独立一屏）

- **主题两套纸**：白天的纸 / 夜里的纸（也可以跟随系统）
- **字号三档**：小 / 中 / 大（和系统 `fontScale` 相乘）
- **动效开关**（也跟随系统「减少动态效果」）
- **印章款式三档**：经典（描边圆）/ 细线 / 实底——母题不换，只换笔触
- **通知**：权限状态 + 到点提醒总览入口

### 长图 · 六种，全部 1080×1920

报告卡（卡片版 / 杂志版）、年度总结、单品、搭配、摘录、菜单。

**它们永远是白天的纸**——这张图是发给别人看的，夜里存一张黑底长图贴进群里像另一个 App。
所以 canvas 取色不走主题，走 `tokenLight()`（见 [`docs/HANDOVER.md`](docs/HANDOVER.md) 第 5 节）。

数据薄到画不出来时**宁可不生成**，也不用一条编出来的曲线凑满纸面。

### 原生能力

- **8 个 Capacitor 插件**：app / filesystem / haptics / local-notifications / preferences /
  share / splash-screen / status-bar
- **本地通知**：渠道 `jian-remind`（IMPORTANCE_DEFAULT，锁屏不显示正文）
- **系统分享接收**：别的 App 里选中一段话 → 分享 → 笺，落到 `window.__jianShare`。
  冷启动和热启动两条路都走（`singleTask` 下第二次分享走 `onNewIntent`，不接就会「内容没了」）
- **真夜间模式**：夜纸 `#1b1917`，CSS 与原生 `res/values-night` 同值；系统条图标跟着翻
- **5 枚桌面快捷方式**：衣笺 / 味笺 / 言笺 / 今日 / 记一笔（走 `jian://screen/...`）
- **返回键**：先回上一张纸，站在主屏上才退到后台

## 数据在哪、隐私立场

**数据只在这台设备上。**

- 网页侧一份：`localStorage` 的 `jian.v1`。
- 原生侧另有一份**保险丝**：Capacitor Preferences。localStorage 被系统清掉时（安卓低内存、
  用户清缓存），开机从它捞回来——这是「丢过一次数据」之后加的。
- **不接入系统自动备份**（`AndroidManifest.xml` 里 `allowBackup="false"`）：卸载即清除，
  不会把聊天记录和照片搬进云端。迁移靠「导出 / 导入备份」。
  这一条与商店文案里那三句「只在你设备上」由 `test/backup_claim.py` 对着查。

**不联网也能用。** 三个模块的判定、统计、成就、长图全在本地算。

**网关是可选的。** 填了地址，多两条路：认照片（`/v1/see`）、抄截图（`/v1/recognize`）。
不填时三张笺全部走本地规则引擎，功能照常。

**密钥在仓库外。** 三家视觉模型的密钥写在 `~/.jian/llm_providers.json`——
刻意放在仓库外，因为网关把仓库根目录当静态目录发，落在仓库树里的密钥等于一个下载链接。
网关那一侧还有第二道 deny（`backend/gateway.py` 的 `_DENY_RE`）挡着它被下载。

```bash
npm run gateway       # 起网关，默认只听 127.0.0.1:8787
npm run gateway:lan   # 要让手机连：绑 0.0.0.0，并把自己的局域网地址打出来
npm run providers     # 逐家真跑一遍认衣服 / 抄截图（要网络与密钥，不进 npm run check）
```

浏览器开 `http://127.0.0.1:8787`（或双击 `index.html`，再在「册」里填同一个地址）；
手机上填那台机器的**局域网地址**——填 `127.0.0.1` 一定没用，那是手机自己的回环。
接口字段约定见 [`GATEWAY.md`](GATEWAY.md)。

**上限会说出来。** 每个集合都有上限（柜子 36 / 笺册 24 / 言笺 200 / 买菜 120 /
行为流水 400 ……共 17 处裁剪），超过时会告诉你丢了几件、丢的是什么、能不能补回来，
不会一边删一边显示「已用 56%」。

## 目录结构

| 路径 | 职责 |
|---|---|
| `index.html` | 骨架：17 个 `<section class="screen">`、24 个 `<script>`、10 个 `<link>` |
| `config.js` | `JIAN_CONFIG`：`endpoint` 留空 = 全本地；`version` 是界面页脚唯一的版本号来源 |
| `engine.js` | 本地规则引擎：色差判定、菜库（63 道）、菜与话的切分、时间解析、上菜顺序 |
| `api.js` | 统一网关 `JianAPI`，失败**自动回落本地并说清是谁算的** |
| `state.js` | 数据层：localStorage、schema 迁移（`SCHEMA = 3`）、导入数据逐项钳位、17 处裁剪上限、钱包 |
| `theme.js` | 主题 / 字号 / 动效 / 印章款式 → 写到 `<html data-*>` |

**为什么是传统 `<script src>` 而不是 ES module**：`file://` 双击要能跑，而
`<script type="module">` 在 `file://` 下会被 CORS 挡住。代价是**加载顺序就是依赖顺序**——
`state.js` 在 parse 期就执行 `normalizeState()`，它调的函数必须在那之前就位。
这条踩过两次白屏，细节和「新增文件要同时改三处」都在
[`docs/HANDOVER.md`](docs/HANDOVER.md) 第 1 节。

## 常用命令

| 命令 | 跑多久 | 跑什么 |
|---|---|---|
| `npm test` | **约 12 秒** | `fast` 八道：锚点 preflight（1 秒）/ 引擎 200 条 / 两端一致性 170 条 / 网关 HTTP 41 条 / `allowBackup` 陈述 / 商店陈述 55 条 / 设备门守卫 52 条。**不用浏览器、不碰真设备**。新克隆尚无 APK 时仅跳过 3 条二进制产物核验，出包后自动严格检查 |
| `npm run test:v06` | **约 10 分钟** | 0.6.0 那 9 道浏览器门（要本机 Edge，headless）：smoke / light_audit / 衣 / 味 / 言 / 笺谱 / 长图 / 册 / 无障碍。最后一门 a11y 最慢（3 分钟），前面八道两分钟左右一道 |
| `npm run test:e2e` | **20 多分钟** | 老六道：全流程 e2e / 网关 e2e / 对比度扫描 / 断网重开 / 帧耗时 / 「按了没反应的控件」 |
| `npm run test:pkg` | **几秒** | 只验产物，八项：www 漂移 / 安卓资产 / cap 配置副本 / 墨色对账 / sw 清单 / 载荷重量 / APK+AAB 里是哪版前端 / 桌面快捷方式 |
| `npm run test:gate` | **十几分钟** | 守门自检：395 段「只改一处」的注入，每次都必须炸（赶时间用 `--only 关键词` 只跑新加的那几条） |
| `npm run test:ship` | **几十秒（要联网 + gh 登录）** | 上架前那一趟：GitHub 上那份隐私政策 == 仓库里的源（逐字节），再把公开那一页渲染出来量（360 宽、无站外请求、控制台干净）。**这一档不许有跳过** |
| `npm run check` | **40 分钟以上** | `all`：以上全部 + fuzz 深扫 1400 例 + 三处产物漂移。发版前跑这个 |
| `npm run audit` | 几分钟 | 差分 fuzz 深扫，1400 例，要求漂移 0；菜单词池从菜库现读 |
| `npm run build-www` | 1 秒 | 按白名单把 H5 拷进 `www/`（每次先清空），顺带对一遍版本号 |
| `npm run cap:sync` | 几秒 | `build-www` + `npx cap sync android` |
| `npm run android` | 约 1–2 分钟 | debug APK |
| `npm run release` | 约 2–3 分钟 | 正式签名 APK + AAB |
| `node scripts/test.mjs <组>` | — | 单跑某一组：`fast` / `v06` / `e2e` / `gate` / `audit` / `pkg` / `ship` / `all` / `sw` |

零碎但好用的：

```bash
python test/gate_selfcheck.py --preflight   # 1 秒：锚点还在不在（改完源码就跑它）
python test/e2e_only.py 8                   # 只跑 e2e 的第 8 节
node test/engine.test.mjs                   # 引擎用例单独跑
JIAN_DEAD_ONLY=标签 python test/dead_controls.playwright.py   # 窄跑诊断
```

`npm` 那几条已经代劳了 `PYTHONIOENCODING=utf-8`；手敲 python 时记得加上，
否则 Windows 终端里中文是 GBK 乱码。

**改 `engine.js` 的判定规则时，必须同步改 `backend/gateway.py`，然后跑 `npm test`。**
两端判定口径漂了，`consistency` 会先炸。

### 关于这些门

`test:gate` 保证别的门不是摆设：它把源码临时改坏一处、要求对应那道门必须 FAIL，
跑完校验字节还原。之前出现过「`consistency` 28 项全绿，两端却漂了 300 多例」——
norm 漏字段、用例覆盖不到、词表没对账。所以：
**一条没有自检的守门，等于没有守门。**

新增屏幕 / 新交互要补测试，两条路选一条：

- 结构不变量（「每枚控件按了有反应」「对比度过 AA」）→ 加进共享门禁（`dead_controls` / `contrast`）；
- 这一屏的业务行为 → 新建 / 扩展 `test/<lane>_v06.playwright.py`。
